# ArtisanChain

A blockchain-based artisan craft authentication and reputation system on Stacks. Artisans earn tokens through peer verification of craftsmanship, buyer endorsements, and quality assessments. Ensures authenticity and builds trust in handmade and artisanal products.

## Features
- Artisan registration and craft documentation
- Peer craft verification system
- Buyer endorsement mechanism
- Craftsmanship quality ratings
- Token incentives for validators and high-quality artisans
